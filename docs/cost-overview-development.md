# 비용 전체 화면 개발 프롬프트

예약에서 보이는 항목을 비용 첫 화면에서도 찾고 수정할 수 있게 한다. 아이폰에서 보기 좋고 한 손으로 편하게 쓰는 화면 구성까지 완료 조건으로 삼는다.

## 화면과 디자인

- iOS 비용은 여행 전·중·후 모두 기본 ‘전체’로 연다. 큰 전체 예상 금액, 남은 예산/초과 금액, 결제 완료·예정 요약, 전체 내역 순서로 구성한다.
- With J의 기존 종이 배경·강조색·서체·여백 토큰을 사용한다. 요약은 시선이 모이는 카드, 내역은 종류 아이콘·이름·날짜·상태·오른쪽 금액이 정렬된 목록으로 만든다. 큰 글자에서는 줄을 자연스럽게 나눈다.
- 필터는 전체·예약·그 외 비용으로 간결하게 두고, 날짜별 보기는 별도 보조 동작으로 제공한다. 설명은 필요한 항목에 한 줄만 둔다.
- 비용 추가는 하단 안전 영역에 둔다. iOS 터치 44pt 이상, 웹 48px 이상. 키보드가 열린 편집기에서도 저장·실패 안내·재시도가 보인다.
- 웹은 기존 모바일 비용 창을 확장하고 데스크톱 비용 칩도 같은 창으로 연결한다. 예약 관리 창은 그대로 유지한다.

## 데이터와 연결

- 서버 응답에 전체 목록을 하위호환으로 추가한다. 저장 구조·환산·합계·숙박 배분 규칙은 바꾸지 않는다. 기존 categories의 날짜별 배분 줄을 그대로 전체 목록으로 사용하지 않는다.
- 항공·숙박·렌터카 예약, 장소 비용/예약 정보, 여행 단위 항목, 하루 추가 지출, 계산된 교통비를 모두 찾을 수 있게 한다.
- 항공·숙박·렌터카는 총액 한 줄이다. 연박 장소도 원래 비용 한 줄로 표시하고 날짜별 배분은 상세에서 확인한다. 전체 목록의 합계는 기존 전체 예상 비용과 일치해야 한다.
- 실제 bookingId/렌터카 연결은 ‘예약 연결’, 명소 personalStatus BOOKED는 ‘예약 완료’로 구분한다. 예약이 있다는 이유로 비용 항목을 복제하지 않는다.
- 예약 금액이 미정이고 연결된 숙소에 금액이 있으면 한 항목으로 묶고 ‘장소에 입력한 금액’을 표시한다. 원본 금액 우선순위는 유지하고 실제 금액 원본 편집기로 연결한다.
- UNKNOWN과 PARTIAL을 각각 ‘금액 미정’, ‘일부 금액’으로 표시한다. 무료는 FREE일 때만 표시한다. 예약 금액 0의 기존 미정 규칙을 무료로 바꾸지 않는다.
- 원본 편집 대상을 응답에 실어 항목을 눌러 같은 예약·장소·비용을 수정한다. iOS에 금액 계산·배분을 복제하지 않는다. 계산된 교통비는 추정 표시와 날짜 상세 연결을 제공한다.
- 수정 후 양쪽 화면과 합계를 갱신한다. 취소·저장 후 목록 위치를 유지하고, 실패하면 초안을 보존한다. 응답 유실 후 재시도와 읽기 전용도 검증한다.
- 새 목록 필드가 없는 옛 API에서는 기존 두 묶음 화면을 유지해 입력이 사라지지 않게 한다.

## 구현 순서와 검증

1. API 목록·원본 참조·중복 방지와 합계 불변 테스트 → API PR.
2. iOS 첫 화면·전체 목록·원본 편집·시뮬레이터 상호작용 → API PR에 의존하는 iOS PR.
3. 웹 비용 창·같은 순수 로직·모바일/데스크톱 상호작용 → API PR에 의존하는 웹 PR.

운영 계정·데이터를 사용하지 않는다. 합성 데이터로 항공 미정, 숙박 총액/장소 금액 폴백, 예약 완료 입장권, 여행 단위/하루 항목, 일정 밖 연박, PARTIAL, 무료, 저장 실패·재시도, 오래된 응답, 읽기 전용을 확인한다.

아이폰 변경 전후 화면을 남기고 실제 입력·저장·취소를 시뮬레이터로 확인한다. 웹 320/375/430px와 데스크톱, iOS 큰 글자와 밝고 어두운 화면을 확인한다. 정적 렌더나 테스트 통과만으로 디자인 검증 완료라고 하지 않는다.

웹 버전을 올리고 필수 게이트를 실행한다. PR에 검증 통과/실패/미확인을 구분하고 변경 화면과 되돌리는 방법을 기록한다. PR까지만 작성한다. merge는 배포이므로 별도 요청을 기다린다.

## 현황: 예약과 비용 목록의 차이

| 원본 | 예약 목록 | 기존 비용 첫 화면 | 개선 후 |
|---|---|---|---|
| 항공·숙박·렌터카 | 표시 | 예약 결제 탭에만 | 전체 목록 총액 한 줄 |
| 장소에 붙인 예약 정보 | 표시 | 현지 결제 → 날짜별 상세 | 전체 목록에서 같은 장소로 연결 |
| 여행 단위 항목 | 예약 정보가 있으면 표시 | 예약 결제 탭 | 전체 목록 |
| 하루 추가 지출 | 예약 정보가 있으면 표시 | 현지 결제 → 날짜별 상세 | 전체 목록 |
| 예약 미정 + 연결 숙소 금액 | 예약 표시 | 장소 금액으로 집계 | 연결된 한 줄, 금액 출처 표시 |
| 금액 미정·일부 | 예약 상태에 따라 표시 | 날짜/탭에 분산 | 상태를 명시하고 목록에 유지 |
