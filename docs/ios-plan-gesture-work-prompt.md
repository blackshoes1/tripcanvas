# iOS 일정 화면 터치·스크롤 개선 프롬프트

With J 네이티브 iOS 앱의 일정 화면에서 날짜 스와이프가 세로 스크롤과 겹치고, 일정 행에서 스와이프를 시작하면 편집 화면이 열리는 문제를 개선해줘.

- 최신 main 기준 별도 fix 브랜치에서 진행한다. 기존 팔레트 작업과 다른 변경을 섞지 않는다.
- TripPlanView의 List, 일정 행 터치, 날짜 스와이프, 애니메이션과 편집 모드의 제스처 관계를 확인한다.
- 짧은 탭만 일정 편집을 연다. 가로·세로 드래그와 취소된 스와이프는 편집을 열지 않는다. VoiceOver에서도 편집할 수 있어야 한다.
- 처음 충분히 움직였을 때 가로/세로 의도를 결정하고 손을 뗄 때까지 유지한다. 세로로 시작했다가 대각선으로 움직여도 날짜를 바꾸지 않는다.
- 가로 날짜 전환 중 세로 목록이 함께 움직이지 않게 한다. 첫날·마지막 날 경계를 지키고, 짧은 드래그는 날짜를 바꾸지 않는다.
- 손가락 추적 offset 복귀와 날짜 슬라이드가 겹치지 않도록 전환을 단순화한다. 동작 줄이기 설정을 존중한다.
- 편집 모드에서는 날짜 스와이프를 막고 기존 삭제·순서 변경을 보존한다. 지도 제스처와 상단 날짜 칩도 유지한다.
- 도메인 판단·API·서버·여행 저장 형식은 바꾸지 않는다. iOS 17 최소 지원을 유지한다.
- 방향 고정·임계 거리·취소·경계와 편집 모드에 필요한 회귀 검증을 추가하고 iOS 빌드·XCTest를 실행한다. 실제 터치 검증과 순수 로직 테스트를 구분해 보고한다.
- 프롬프트, 변경, 검증 결과를 파일/커밋으로 남긴다. 실기기 미검증을 통과로 보고하지 않고, 이번 요청만으로 프로덕션 merge·TestFlight 배포는 하지 않는다.
