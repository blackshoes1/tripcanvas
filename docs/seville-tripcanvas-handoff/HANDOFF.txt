1. 이 작업의 목적과 사용자 요구
사용자와 아내가 스페인 신혼여행 때 함께 사용할 한국어 개인 관람 가이드입니다.
최초 요청은 오디오 가이드였으며, 현재는 사진·지도·텍스트를 갖춘 웹 가이드로 확장됐습니다.
역사적 사실·작품의 제작 과정·사건·도난과 복원·계약 기록 같은 내용을 풍성하게 하는 것이 중요합니다.
단순히 화려한 형용사를 늘리는 방식은 사용자가 명시적으로 원하지 않습니다.
첫 방문자도 사진과 눈앞의 특징으로 장소를 찾고 해당 해설을 들어야 합니다.
사용자는 유료인 Runway를 거절했고 무료 제작을 선호합니다. 무료라는 이유만으로 품질을 타협하지 마세요.
브라우저 기기 음성은 '별로', 이후 제시한 세 가지 샘플은 '다 별로임'이라는 평가를 받았습니다.
현재 가장 중요한 미완성 항목은 자연스러운 한국어 도슨트 음성입니다.

3. 파일 우선순위와 버전 차이 — 반드시 읽기
최신 기준은 sites/seville-field-guide-publish/dist/content.js의 window.GUIDE_DATA입니다.
이를 읽기 쉽게 추출한 guide-data-14-stops.json도 함께 넣었습니다.
낭독할 최신 원고는 dist/narration/01_narration.txt ~ 14_narration.txt입니다.
동일한 통합본은 seville-guide/seville-cathedral-14-stop-narration.txt입니다.

seville-guide/seville-cathedral-korean-guide.txt와 seville-cathedral-find-your-stop.pdf는 이전 12트랙 버전입니다.
옛 TXT 헤더에는 낭독 본문 18,770자로 표시돼 있습니다. 최신 14장소와 동일한 파일로 취급하지 마세요.
웹판은 08 대성물실의 고야 이야기와 10 성가대석의 십자가상 이야기를 다른 장소로 분리했습니다.
13 고야는 Sacristía de los Cálices, 14 자비의 그리스도는 Capilla San Andrés입니다.
두 장소를 08 또는 10 위치에서 그대로 읽으면 현장 설명과 대상이 어긋납니다.
이전 PDF는 참고용으로 보존했으며, 최신 14장소 PDF를 새로 만들지는 않았습니다.

최신 full 본문 합계는 16,105자, summary 합계는 2,059자입니다. 도착·다음 이동은 이 수치에 포함되지 않습니다.
음성을 만들 때 메뉴명, 출처 ID, 파일 제목을 읽지 말고 실제 낭독 본문을 사용하세요.

5. 웹 소스 구조와 실행 방법
프레임워크·서버·로그인·데이터베이스 백엔드 없이 HTML/CSS/JavaScript로 만든 정적 앱입니다.
다른 저장소의 프레임워크로 이미 통합됐다고 가정하지 마세요.

sites/seville-field-guide-publish/dist/
  index.html                 화면 구조와 진입 파일
  style.css                  반응형 스타일
  app.js                     화면·지도·TTS·오디오 파일·관람 기록
  content.js                 14장소 데이터와 출처
  assets/photos.json         사진 경로·작가·라이선스·출처·수정 내역
  assets/*.jpg               실제 사진
  narration/*.txt            최신 14장소 낭독 원고
  sw.js, cache-files.json    오프라인 캐시
  manifest.webmanifest       웹 앱 메타데이터

로컬 실행 예시 — 압축을 푼 묶음의 최상위 폴더에서:
  python -m http.server 8765 --bind 127.0.0.1 --directory sites/seville-field-guide-publish/dist
  브라우저: http://127.0.0.1:8765/
실행 중인 서버는 Ctrl+C로 종료합니다. 이 인계 작업에서 서버를 새로 상시 실행하지 않았습니다.
여러 파일로 된 index.html을 file://로 여는 경우 fetch와 Service Worker 기능이 제한됩니다.
단일 HTML은 seville-guide/seville-cathedral-pocket-guide.html을 사용합니다.
휴대폰 파일 미리보기가 브라우저 실행을 보장하지 않으므로 실제 기기 동작을 별도로 확인하세요.

6. 기능별 실제 구현과 한계
- localStorage의 our-seville-v1: 현재 장소, 핵심/전체 모드, 설정, 관람 완료·건너뛰기.
- IndexedDB our-seville-audio-v1 / audio: 장소 ID별 오디오 Blob. 브라우저·기기 간 동기화 없음.
- 가져오는 파일 이름의 선행 1~2자리 숫자를 장소 ID로 해석합니다.
  예: 05_중앙제단.mp3, 13_고야.mp3. 번호 없는 단일 파일은 선택한 장소에 연결할 수 있습니다.
- 파일을 연결하면 그 파일을 우선 재생하며, 없으면 speechSynthesis의 한국어 음성을 사용합니다.
- 파일 오디오에는 핵심/전체 모드가 적용되지 않습니다. 현재 오디오 저장 키는 장소 ID 하나뿐입니다.
- 속도 설정은 기기 TTS에만 적용됩니다. 두 길이의 파일을 지원하려면 스키마와 UI를 함께 설계해야 합니다.
- 기기 TTS는 summary/full 본문을 읽습니다. arrival/next가 자동으로 붙지는 않습니다.
  반면 내보낸 낭독 TXT에는 arrival, full, next가 함께 있습니다. 제작할 오디오의 범위를 일관되게 정하세요.
- 오디오 종료 후 자동으로 다음 장소를 재생하지 않습니다.
- 일괄 가져오기는 MP3/WAV/M4A/AAC/OGG를 받지만 실제 디코딩은 브라우저 코덱 지원에 달립니다.
- 오프라인 정적 자산 목록은 35개이며 Service Worker·Cache API를 사용합니다.
  정적 파일 저장 완료가 기기 TTS의 오프라인 동작이나 iOS 백그라운드 재생 보장을 뜻하지 않습니다.
- 사진 출처와 라이선스는 assets/photos.json에 있습니다. 수정·재배포 시 표시를 보존하세요.

7. 음성 샘플, 재현 코드와 현재 판단
[이전 비교 — 사용자 거절]
seville-guide/voice-samples/seville-voice-comparison.mp3
Supertonic 여성 F1, 여성 F2, 남성 M1의 비교본. 사용자가 셋 모두 마음에 들지 않는다고 답했습니다.
sample-info.json에 당시 생성 설정이 있습니다. 이를 이미 선택된 목소리로 되돌리지 마세요.

[최신 — 사용자 미승인]
seville-guide/voice-samples/seville-docent-voice.mp3
모델: Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice
revision: 0c0e3051f131929182e2c023b9537f8b1c68adfe
speaker: Sohee / WAV 기준 24kHz 모노, 27.28초
중앙 제단의 1482년·1564년·여든두 해를 설명하는 짧은 시험본입니다.
seville-docent-qwen-info.json에 원문과 말투 지시가 있습니다.
원본 seville-docent-qwen.mp3와 공개 파일은 동일한 복사본이므로 공개 파일 하나만 넣었습니다.

guide-work/generate_qwen_docent.py는 고정 문장을 합성하는 샘플 코드입니다.
전체 14장소를 문단별로 합성·검수·합치는 배치 파이프라인은 구현돼 있지 않습니다.
현재 코드는 cuda:0, torch.bfloat16, SDPA, local_files_only=True에 의존하고 CPU 대체 경로가 없습니다.
모델은 guide-work/qwen-voice/model, 보조 모듈은 guide-work/voice-libs를 예상합니다.
guide-work/check_docent_audio.py는 로컬 Whisper 모델 qwen-voice/asr와 CUDA에 의존합니다.

기존 환경 기록(즉시 설치 가능한 범용 요구사항 파일이 아님):
Python 3.12.10 / torch 2.11.0+cu128 / qwen-tts 0.1.1 / transformers 4.57.3 /
accelerate 1.12.0 / numpy 2.5.1 / soundfile 0.14.0 / soxr 1.1.0 / lameenc 1.9.0.
대형 모델 본체(약 3.83GB), speech_tokenizer, ASR 모델, 가상환경, 의존 모듈 폴더는 묶음에 넣지 않았습니다.
기존 컴퓨터에 남아 있을 수 있어도 다른 컴퓨터에서 복사만으로 실행된다고 약속하지 마세요.
재현 시 장비·모델 접근·라이선스·최신 설치 조건을 별도 확인하세요.

guide-work/qa/qwen-audio-check.json은 자동 전사 기록입니다.
전사에서 '여든두 해죠'가 '여던도 예죠'로 나왔습니다. 인식 오류일 수 있으므로 실제 청취로 판단해야 합니다.
피크/RMS와 전사에 큰 누락이 없다는 이유만으로 목소리 품질을 합격 처리하지 마세요.

현재 dist에서 단일 HTML만 다시 묶는 명령은 묶음 최상위에서 다음과 같습니다.
  python guide-work/build_portable_guide.py
이 명령은 묶음 안의 seville-guide/seville-cathedral-pocket-guide.html을 덮어씁니다.
PDF 생성 코드는 참고용이며 폰트·PDF 라이브러리 및 해당 제작 워크플로를 별도로 준비해야 합니다.
guide-data-14-stops.json은 현재 content.js에서 추출한 스냅샷이며 앱이 직접 읽는 파일은 아닙니다.
