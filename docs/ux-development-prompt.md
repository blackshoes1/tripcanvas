# With J UI/UX 개발 프롬프트

## 목표

2026-09-13 최신 main(5c16deb, tc-v195) 검토에서 확인한 사용 흐름 문제를 수정한다. 사용자가 입력을 잃지 않고, 저장 상태를 이해하며, 여행 전/중 어디서든 예약과 협업에 접근할 수 있게 한다. 원본 작업과 미커밋 문서는 보존하고 feat/ux-review-improvements 브랜치에서 진행한다.

## 구현 요구사항

1. iOS 장소·예약 편집은 비동기 저장 성공 후 닫는다. 실패·충돌 때 입력을 유지하고 원인을 표시한다. 변경한 입력을 취소할 때 폐기를 확인한다. 동시 쓰기를 막고 저장 성공 여부를 실제 결과로 반환한다. 충돌을 조용히 덮어쓰지 않는다.
2. iOS 여행 목록의 최초 로딩, 서버 실패, 정상 빈 목록, 캐시를 구분한다. 실패 화면에서 다시 시도할 수 있어야 한다.
3. 웹 빈 여행에 이전 여행 지도를 남기지 않는다. 목적지 확인 전에는 첫 장소 검색 안내를 표시하고, 사용자가 고른 위치로 지도를 연결한다. 목적지 이름만으로 좌표나 시간대를 추측하지 않는다.
4. iOS 여행 공통 영역에 예약·같이 짜기·가고 싶은 곳을 배치한다. 여행 시작 여부와 장소 개수에 따라 진입점이 사라지지 않아야 한다.
5. 웹 온보딩에 포커스 순환, 배경 inert, 닫은 뒤 복귀를 적용한다. 최초 포커스는 새 여행 만들기에 둔다.
6. 웹 장소 기본 폼에서 예약·입장 시각, 내가 정한 도착 시각, 머무는 시간을 구분한다. 자동 예상과 직접 정한 시각을 혼동시키지 않는다.
7. 웹 저장 상태를 지속적으로 표시한다. 로컬 저장, 서버 전송 중, 성공, 실패, 충돌, 읽기 권한 상태를 실제 데이터에서 도출한다. 쓰기 권한이 없는 상태에서 재시도하지 않는다.
8. iOS 예약 딥링크는 예약으로, 제안/다시 맞추기는 지금 화면으로 연결한다. 미지원 목적지는 안내한다. 실행 중과 최초 진입 모두 목적지를 유지한다.
9. With J 제품명을 통일하고 From J는 제안 서명으로만 쓴다. 웹 메뉴를 여행·협업·파일 작업으로 묶고 예약 및 공유의 결과를 명확히 표현한다.
10. iOS 상태 배지 텍스트 대비를 강화하고 완료·건너뛰기 동작에 보이는 메뉴를 제공한다.

## 후속 확장 후보

아래는 별도 도메인/계약 설계가 필요한 확장 로드맵이다. 위 결함 수정과 분리해서 구현·검증한다. 이번 수정 결과에 구현하지 않은 기능을 완료로 표시하지 않는다.

- 출발 전 준비 요약: 위치/시간대 등 확인할 항목에서 해당 편집으로 연결.
- 일정 변경 전후 비교: 기존 엔진 미리보기에서 이동/제외 장소와 보호된 예약을 설명하고 되돌리기 제공.
- 위치 없는 장소 일괄 확인: 검색 후보를 사용자가 확인한 후 연결.
- 지난 여행 보관·검색: 여행 삭제 없이 예정/진행/지난 여행 구분.
- 길찾기 앱 선택: 이동수단 및 설치 앱에 맞는 검증된 딥링크 사용.

## 제약

- 판단은 adaptive.js, iOS는 서버 결과 표시. 원문 JSON의 알 수 없는 필드 보존.
- CAS/revision과 편집 권한을 유지한다. 외부 입력은 확인 없이 저장하지 않는다.
- NAS/API 배포 설정·DB/RLS·기술 식별자는 변경하지 않는다.
- XSS 이스케이프와 safeUrl을 유지한다. 오프라인 지도 캐싱은 하지 않는다.
- 웹 수정은 npm run bump:version을 실행한다.
- main 직접 커밋/푸시 금지. merge는 즉시 배포이므로 검증 결과가 준비되기 전에는 하지 않는다.

## 검증 및 산출물

- 오프라인/500/409 저장 실패 후 초안 보존, 실패 후 재시도, 빈 목록 실패, 예약 딥링크를 XCTest로 확인한다.
- 온보딩 키보드 순환·초기 포커스·배경 차단, 새 여행 지도 안내, 시간 필드, 저장 상태를 통합/E2E로 확인한다.
- 모바일 390×844와 데스크톱에서 agent-browser로 변경 화면 확인.
- npm run verify:all 전체 실행. PASS/FAIL/SKIP과 원인을 기록하며 SKIP을 통과로 표현하지 않는다.
- 개발 결과 문서에 구현 내용, 남은 범위, 실제 실행한 검사, 릴리스 전 필요한 검증을 작성한다.
