# iOS 일정 제스처 개선 결과

## 범위

개발 지침은 [실행 프롬프트](ios-plan-gesture-work-prompt.md)에 있다. `bb74c41` 기준 별도 `fix/ios-plan-gestures` 브랜치에서 작업했다. 원래 작업 공간의 미병합 팔레트 변경은 포함하지 않았다. API·도메인 엔진·여행 저장 형식은 변경하지 않았다.

## 변경

- 일정 행의 일반 버튼을 명시적인 탭 표면으로 바꿨다. UIKit 탭 인식기가 시작 위치에서 12pt 이상 움직인 순간 실패하도록 해, 짧게 끌다가 놓거나 돌아와도 편집을 열지 않는다. 손을 뗄 때도 최종 이동량을 검사한다. 정상 탭과 VoiceOver 기본 동작은 같은 권한 확인 함수를 사용한다.
- 행에는 드래그 인식기를 붙이지 않는다. 행의 드래그 인식기가 목록 스크롤을 막는 것을 시뮬레이터에서 확인했기 때문이다. 탭 인식기는 상위 제스처와 동시 인식을 허용한다.
- 날짜 이동은 처음 충분히 움직인 방향을 고정한다. 세로·대각선으로 시작한 손이 나중에 가로로 움직여도 날짜를 바꾸지 않는다. 가로로 확정한 동안만 세로 스크롤을 잠그고, 편집 모드에서는 날짜 제스처를 제외한다.
- 방향 상태는 `onEnded`까지 유지한다. `GestureState`는 제스처 활성 여부와 취소 감지에만 사용하고, 완료·취소 시 방향 상태를 초기화한다. 임시 상태만으로 방향을 보존했을 때 종료 시 날짜 이동이 누락되는 것을 시뮬레이터에서 확인했다.
- 손가락 추적 offset을 제거해 원위치 복귀와 날짜 슬라이드가 겹치지 않게 했다. 이전·다음 목록은 고정된 같은 영역에서 전환하고 바깥으로 넘치는 부분은 자른다. 기존 동작 줄이기 설정은 유지한다.

## 검증 범위

- 방향 고정, 짧은 이동/원점 복귀, 앞뒤 날짜 경계, 편집 모드와 빈 일정에 대한 XCTest 5개를 추가했다.
- iPhone 17 Pro / iOS 26.5 시뮬레이터의 격리 SwiftUI List 하네스에서 XCUITest 2개를 실행했다. 실제 제품의 날짜 제스처 함수·애니메이션과 최종 `PlanSpotTapSurface`를 사용하되, 일정 행은 45개 텍스트로 대체했다. 서버·계정·운영 데이터는 사용하지 않았다.
- 하네스 통과 항목: 35pt 짧은 드래그가 편집을 열지 않음, 이후 정상 탭 편집, 행 위 가로 스와이프의 날짜 이동, 마지막 날 경계, 세로 드래그의 실제 목록 스크롤, 편집 모드에서 날짜 이동 차단.
- 하네스는 실제 TripPlanView 전체 사용자 흐름이나 실기기 검증을 대체하지 않는다. 단순 TapGesture와 행별 ExclusiveGesture는 각각 짧은 이동 오탭·세로 스크롤 실패가 있어 최종 구현에서 제외했다.
- 최소 지원은 iOS 17로 유지했다. 설치된 런타임이 iOS 26.5이므로 iOS 17에서 실제 제스처 동작은 미검증이다.

최종 앱 검증: XcodeGen 생성, iOS XCTest 249개(실패 0), Release 시뮬레이터 빌드 통과. 변경 범위가 iOS UI와 문서이므로 루트/Next 전체 게이트는 이번 작업에서 다시 실행하지 않았다.

## 실기기 후속 확인

1. 장소를 정상 탭하면 편집이 열리고, 천천히 12pt 이상 끌다 놓으면 열리지 않는지 확인한다.
2. 긴 목록을 세로로 읽다가 대각선으로 움직여도 날짜가 바뀌지 않는지 확인한다.
3. 앞뒤 날짜 전환·경계·짧은 스와이프·원점 복귀 후 다음 탭과 스크롤이 정상인지 확인한다.
4. 제스처 중 앱 전환/시스템 취소 후 스크롤 잠금이 남지 않는지 확인한다.
5. 편집 모드의 삭제·순서 변경, 지도 제스처와 날짜 칩 선택을 확인한다.
6. 동작 줄이기와 VoiceOver에서 날짜 선택·일정 편집을 확인한다.

## 참고한 API 계약

[Apple GestureState](https://developer.apple.com/documentation/swiftui/gesturestate)는 비활성 시 자동 초기화된다. [scrollDisabled](https://developer.apple.com/documentation/swiftui/view/scrolldisabled(_:))는 List에도 적용된다. 이 API 설명과 실제 시뮬레이터 터치 결과를 구분해 검증했다.
