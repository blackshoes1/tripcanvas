# 🗺 Trip Canvas

대화로 만드는 멀티시티 여행 동선 플래너 (PWA).
"입력은 대화로, 출력은 지도로" — 도시별 색상 핀, 일자별 필터, 동선 연결, 오프라인 지도를 지원합니다.

## 기능

- **붙여넣기로 초안**: 정해진 형식으로 직접 붙여넣기(AI 없이 즉시, 좌표는 OSM 자동조회) / 토글을 켜면 자연어를 Claude가 정리 (개인 API 키는 브라우저에만 저장)
- **동선 지도**: 도시별 색상 핀, Day 필터, 방문 순서 연결선, 일자 간 이동선
- **앱 내 편집**: 명소 추가(장소 검색/지도 클릭)·삭제·순서 변경, 일자 관리, 메모
- **여행 모드**: 시작일 기준 오늘 일정 자동 표시 + Google 지도 길찾기 연결
- **여행 다중 관리**: 여러 여행 생성, JSON 내보내기/가져오기, 압축 공유 링크
- **PWA**: 홈 화면 설치, 오프라인 실행, "오프라인 준비" 버튼으로 일정 주변 지도 타일 사전 캐시

## 구조

```
├── index.html      # 앱 본체 (단일 파일: UI + 로직)
├── sw.js           # 서비스 워커 (오프라인 캐시 전략)
├── manifest.json   # PWA 매니페스트
└── icon-*.png      # 앱 아이콘
```

빌드 도구 없음 — 정적 파일 그대로 배포합니다.
지도: Leaflet + CARTO 타일 / 장소 검색: Nominatim (OSM) / 저장: localStorage

## 로컬 실행

서비스 워커 때문에 http 서버로 열어야 합니다:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## 배포

Vercel/Netlify에 Git 연동 시 push마다 자동 배포됩니다. 별도 빌드 설정 불필요 (Framework: Other, Output: 루트).
